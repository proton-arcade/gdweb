# Games

This directory is reserved for standalone game projects or experiments kept alongside
Geometry Dash Web.

## Current game

The repository currently contains one playable game: Geometry Dash Web. Open `index.html` to
launch it. The game code is in `website/js/`, with its assets and level data in
`website/assets/`; it does not currently live in this directory.

## Adding a game

Give each additional game its own subdirectory and include a short README with its entry
point, controls and any setup instructions.
