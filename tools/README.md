# Tools

This directory is for optional developer utilities that help build, validate or maintain
Geometry Dash Web. These tools are not loaded by the browser game.

## Current contents

There are no standalone tool scripts here yet. The game has no build step or runtime
dependencies; open `index.html` to play it. Its JavaScript source is in `website/js/`.

## Adding a tool

Keep each helper focused, and document its purpose, prerequisites, command to run it and any
files it reads or generates. Avoid checking in generated output unless it is needed by the
game.
